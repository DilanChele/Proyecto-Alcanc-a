# 🐷 Alcancía Inteligente

Un sistema de ahorro interactivo e inteligente basado en el Internet de las Cosas (IoT). Este proyecto integra hardware y software para automatizar el conteo de monedas y visualizar el progreso de ahorro en tiempo real a través de una aplicación móvil.

## 🚀 Acerca del Proyecto

El objetivo principal de este proyecto es fomentar la educación financiera mediante una herramienta física y digital. La alcancía física cuenta con un chasis clasificador diseñado a medida y utiliza sensores para identificar y calcular los depósitos automáticamente. Toda la información se procesa mediante un microcontrolador y se sincroniza en la nube, permitiendo al usuario monitorear sus ahorros desde su smartphone en cualquier momento.

## ✨ Características Principales

* **Clasificación y Conteo Automático:** Uso de sensores infrarrojos para detectar y calcular con precisión el valor de las monedas ingresadas.
* **Sincronización en Tiempo Real:** Los datos del dinero depositado se envían instantáneamente a la nube.
* **Monitoreo Móvil:** Aplicación móvil nativa para visualizar el saldo actual y las metas de ahorro.


## 🛠️ Tecnologías Utilizadas

* **Hardware / Sistemas Embebidos:**
  * **ESP32:** Microcontrolador principal encargado del procesamiento de datos de los sensores y la conexión Wi-Fi.
  * **Sensores:** Infrarrojos para la detección de monedas.
* **Backend / Nube:**
  * **Firebase Realtime Database:** Base de datos NoSQL para almacenar y sincronizar los registros de ahorro en tiempo real.
* **Desarrollo Móvil:**
  * **Android Studio:** Entorno de desarrollo utilizado para crear la aplicación móvil del usuario final.
